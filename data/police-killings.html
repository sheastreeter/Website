Police Killings: Data Explorer

An interactive explorer for the Police Killings and Protest (PKAP) dataset.

Partial dataset. This explorer currently loads the geolocated 2015–2016 records — each a real police killing, with demographics, circumstances, and location. The full Police Killings and Protest (PKAP) dataset extends across additional years and adds the protest-outcome coding at the heart of my research; those layers will be connected as they are finalized. Every record here represents a person who was killed. Please explore accordingly.

This page lets you explore the Police Killings and Protest (PKAP) dataset, an original resource I assemble and code with the Violence and Policing Lab. You can filter the cases by year, race and ethnicity, and armed status, and see the results across the map and charts below. Counts of police killings are known to undercount the true total, because no comprehensive official record exists; the methods note at the end describes the data’s sources and limitations.

data2015 = FileAttachment("pkap_geolocated_2015.csv").csv({ typed: true })
data2016 = FileAttachment("pkap_geolocated_2016.csv").csv({ typed: true })
raw = [...data2015, ...data2016]

monthNum = new Map([
  ["January",1],["February",2],["March",3],["April",4],["May",5],["June",6],
  ["July",7],["August",8],["September",9],["October",10],["November",11],["December",12]
])

// Derive a Date for the time trend; keep everything else as-is.
data = raw.map(d => ({
  ...d,
  date: new Date(d.year, (monthNum.get(d.month) || 1) - 1, +d.day || 1)
}))
groupOrder = ["Black", "White", "Hispanic/Latino", "Asian/Pacific Islander", "Native American", "Arab-American", "Other", "Unknown"]
groupColor = new Map([
  ["Black",                  "#2a78d6"],
  ["White",                  "#eb6834"],
  ["Hispanic/Latino",        "#4a3aa7"],
  ["Asian/Pacific Islander", "#1baf7a"],
  ["Native American",        "#eda100"],
  ["Arab-American",          "#e87ba4"],
  ["Other",                  "#898781"],
  ["Unknown",                "#c3c2b7"]
])
color = d => groupColor.get(d) ?? "#898781"

armedOptions = ["All", ...Array.from(new Set(data.map(d => d.armed))).filter(x => x != null && x !== "").sort()]
viewof selYear = Inputs.select(["All", 2015, 2016], { label: "Year", value: "All" })
viewof groups = Inputs.checkbox(groupOrder, { value: groupOrder, label: "Race / ethnicity" })
viewof selArmed = Inputs.select(armedOptions, { label: "Armed status", value: "All" })
filtered = data.filter(d =>
  (selYear === "All" || d.year === selYear) &&
  groups.includes(d.raceethnicity) &&
  (selArmed === "All" || d.armed === selArmed)
)
html`<p class="lead" style="margin-top:0.5rem;">
  <strong>${filtered.length.toLocaleString()}</strong> cases shown
  <span style="color:#898781;">of ${data.length.toLocaleString()} total · 2015–2016</span>
</p>`

Where cases occurred

L = require("leaflet@1.9.4")
baseMap = {
  const el = html`<div style="height:480px;border-radius:8px;overflow:hidden;border:1px solid rgba(11,11,11,0.10);"></div>`;
  const m = L.map(el).setView([39.5, -98.35], 4);
  L.tileLayer("https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png", {
    maxZoom: 12,
    attribution: "© OpenStreetMap contributors"
  }).addTo(m);
  el.value = m;
  requestAnimationFrame(() => m.invalidateSize());
  return el;
}
markers = {
  const m = baseMap.value;
  const layer = L.layerGroup().addTo(m);
  invalidation.then(() => layer.remove()); // clear when `filtered` changes
  for (const d of filtered) {
    if (!Number.isFinite(d.lat) || !Number.isFinite(d.lon)) continue;
    const c = color(d.raceethnicity);
    L.circleMarker([d.lat, d.lon], {
      radius: 4, color: c, weight: 1, fillColor: c, fillOpacity: 0.55
    })
      .bindTooltip(
        `<strong>${d.name ?? "Name unavailable"}</strong>` +
        `${d.age ? ", " + d.age : ""}<br>` +
        `${d.raceethnicity} · ${d.gender ?? ""}<br>` +
        `${d.city ?? ""}, ${d.state ?? ""} · ${d.year}<br>` +
        `${d.classification ?? ""} · armed: ${d.armed ?? "Unknown"}`
      )
      .addTo(layer);
  }
  return layer;
}

Methods & limitations

This section will be completed with the full dataset’s documentation. The Police Killings and Protest (PKAP) dataset records police killings in the United States, geolocates each case, and — in its complete form — codes each for whether it was followed by protest. The records shown here cover 2015 and 2016 and are compiled from public records and journalistic sources; my research team arbitrates each coding decision. Counts of police killings undercount the true total, because no comprehensive official record exists, and categories such as race, ethnicity, and armed status carry their own measurement uncertainty. I will state the full coverage window, sources, and coding rules here, and I will publish only the variables designated for public release. Because each record is a person who was killed, I ask that the data be used with corresponding care.
